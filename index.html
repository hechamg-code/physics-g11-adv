خطوات إنشاء جدول Google Sheets لاستقبال أسماء الطلاب ودرجاتهم تلقائياً (مجاناً 100%):
  1. افتح ملف Google Sheets جديد في حسابك على جوجل، ومن القائمة العلوية اختر: Extensions (الإضافات) ⬅ Apps Script.
  2. امسح أي كود موجود هناك، واضغط على الزر أدناه «📋 نسخ كود Google Apps Script الجاهز» والصقه هناك، ثم اضغط حفظ (💾).
  3. في أعلى يمين صفحة Apps Script اضغط Deploy (نشر) ⬅ New deployment (نشر جديد)، واختر النوع Web app (تطبيق ويب).
  4. اجعل Who has access (من لديه حق الوصول): Anyone (أي شخص) ثم اضغط Deploy وانسخ رابط Web app URL الناتج.
  5. الصق الرابط في الخانة أعلاه (أو أرسله لي في المحادثة لأدمجه لك بشكل دائم داخل ملف index.html قبل رفعه على GitHub Pages).
